CPS530 Lab 10 – Problem 2

I decided to use Tailwind as the front end framework for this problem.
Tailwind allows for a lot of customization on your elements with inline CSS through the class.
I can easily change colours, add tailwind themes and make responsive layouts with this framework.

Framework Used

Tailwind CSS via CDN.

Installation / Setup

The Setup was really easy, I used the development CDN link provided by Tailwind on their website.

How I Built the Page

Used Tailwind utility classes for layout, typography, spacing, colors, and dark mode support. The Bento grid layout is inspired by Tailwind UI: source link.
